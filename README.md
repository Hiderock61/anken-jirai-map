# フリーランス入口アプリ v0.4｜募集探索タブ追加版

募集を探す検索語と入口を持ち、見つけた募集を既存の技能差分判定へ渡す静的SPAです。

## v0.4でできること

- 「探す」と「分解する」のタブ切り替え
- 6カテゴリ・27枚の目的別検索カード
- Google検索とGitHub Issue検索
- 検索語のコピー
- コピー失敗時の手動コピー表示
- 危険ワードの確認リスト
- 見つけた募集メモ
- 募集メモの防護付き端末内保存
- 募集メモから既存の募集文入力・技能候補・差分判定への引き渡し
- 案件カード生成と装備庫への引き渡し

## 使い方

1. 「探す」タブで目的に近い検索カードを選ぶ
2. GoogleまたはGitHubで募集・練習材料を探す
3. 見つけた内容を「見つけた募集メモ」へ貼る
4. 「この募集を分解する」を押す
5. 必要技術を確認し「技能差分を出す」を押す

## 実装範囲

HTML / CSS / JavaScriptのみを使用しています。外部サイトの自動取得、スクレイピング、ログイン、自動応募、AI API、サーバー処理はありません。
