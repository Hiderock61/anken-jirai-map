# AI副業・案件地雷地図 v0.1

AI副業・案件地雷地図は、広告文や案件文を貼って、初心者が「仕事募集なのか」「講座・高額サポート入口なのか」「情報不足なのか」を分解するための静的Webアプリです。

このリポジトリを、**地雷地図アプリの正式箱**として扱います。

---

## このアプリは何？

AI副業、フリーランス募集、在宅ワーク、SNS広告、DM勧誘などの文章には、次のようなものが混ざることがあります。

* 実際の仕事募集
* 講座やスクールへの入口
* 高額サポート販売への入口
* 条件が足りない案件文
* 夢ワードが多く、納品物が見えにくい募集文

このアプリは、それを裁判する道具ではありません。

文章の中にある赤札を拾い、次に確認することを出すための観察道具です。

---

## 目的

目的は、初心者がいきなり財布や個人情報を出す前に、文章を分解することです。

```text id="2k8mwx"
これは仕事なのか？
講座入口なのか？
情報不足なのか？
納品物は何か？
報酬条件は何か？
初期費用はあるのか？
```

このあたりを、画面上で一度止まって確認します。

---

## できること

* 広告文や案件文を貼る
* 気になる条件にチェックを入れる
* 赤札を表示する
* 良い材料も拾う
* 判定結果を見る
* 次に確認する質問を出す
* AIに渡す質問文をコピーする

---

## 判定の考え方

このアプリは、AI APIを使いません。
外部通信もしません。
ローカルのルールベース判定です。

文章内のキーワードやチェック項目を見て、以下のような材料を拾います。

### 赤札として見るもの

* 未経験OKを強く押している
* 高収入、月収、簡単さを強く押している
* LINEやDMへ誘導している
* 初期費用、サポート費用、教材費、講座、スクールの気配がある
* 仕事内容より夢ワードが多い
* 急がせる表現がある

### 良い材料として見るもの

* 納品物が書かれている
* 報酬条件が書かれている
* 作業内容が具体的
* 納期や範囲が書かれている

---

## このアプリがしないこと

* 絶対に安全、絶対に危険とは断定しない
* 法律判断はしない
* 契約判断はしない
* 相手企業の信用調査はしない
* 自動で応募しない
* 外部AIへ自動送信しない
* 入力内容を保存しない
* 決済、ログイン、会員登録はしない

あくまで、文章を読む前の赤札チェックです。

## 使い方

1. `index.html` を開く
2. 広告文・案件文を貼る
3. 気になる条件にチェックを入れる
4. 「赤札チェックする」を押す
5. 判定結果、赤札、良い材料、次に確認することを見る
6. 必要なら AIに渡す質問文をコピーする

GitHub Pagesに置けば、スマホでも使えます。

## 注意

このアプリは、生活防衛と案件観察のためのプロトタイプです。

実際に契約、支払い、個人情報提出、講座購入、仕事応募をする前には、次の情報を別途確認してください。

* 相手の会社名、運営者情報
* 契約条件
* 報酬の支払い方法
* 納品物
* 作業範囲
* 初期費用や月額費用の有無
* 返金条件
* 個人情報の扱い
* 実績や評判

このアプリの判定だけで契約や支払いを決めないでください。
