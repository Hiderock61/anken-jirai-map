# フリーランス入口マップ v0.3｜技能差分発見版

募集文を貼り、必要技術を選び、現在の装備との差分から「次に学ぶ一つ」を出す静的アプリです。

## 役割

入口アプリは、案件を判定するだけではなく、市場が求めるものと現在の装備との差分を見つけ、学習ミッションと案件カードへ変換します。

## v0.3でできること

- 募集文の貼り付け
- 文章から必要技術候補を自動チェック
- 現在装備の状態設定
  - 未習得
  - 試作済み
  - 納品可能
  - 実案件済み
- 足りない技術の表示
- 次の学習ミッションの表示
- 装備庫へ渡す案件カードの生成とコピー
