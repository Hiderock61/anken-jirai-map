# フリーランス入口マップ©️ v0.2

募集・案件・講座・コミュニティの文章を、次の入口へ構造分解する静的Webアプリです。

- 仕事入口
- 学習入口
- 実績作り入口
- コミュニティ入口
- 営業入口
- 搾取入口
- 情報不足

## 本版の役割

入口マップで「何の入口か」を判定し、結果に応じて既存の「フリーランス装備庫」へ渡します。

入口マップ → 得る物と消費を確認 → 次の質問 → 装備庫で実装

## ファイル

- index.html
- style.css
- app.js

外部ライブラリ、API、ログイン、データ送信は使用していません。

## 装備庫URL

`index.html` の `equipmentLink` に次のURLを設定済みです。

https://hiderock61.github.io/freelance-/

公開先が異なる場合は、このURLだけ変更してください。
