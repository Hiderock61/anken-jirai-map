# フリーランス入口アプリ v0.4B｜正式案件カード接続修正版

募集を探す検索語と入口を持ち、見つけた募集を技能差分判定と正式案件カードを通して「フリーランス装備庫 v2.2」へ渡す静的SPAです。

## v0.4Bでできること

- 「探す」と「分解する」のタブ切り替え
- 6カテゴリ・27枚の目的別検索カード
- Google検索とGitHub Issue検索
- 検索語のコピー
- コピー失敗時の手動コピー表示
- 危険ワードの確認リスト
- 見つけた募集メモ
- 募集メモの防護付き端末内保存
- 募集メモから既存の募集文入力・技能候補・差分判定への引き渡し
- 作業内容・納品物・相手へ聞く質問・チェック基準の確認と修正
- 装備庫必須4項目を独立見出しで含む正式案件カードの生成
- 学習ミッション完成条件を含む案件カードのコピー
- フリーランス装備庫 v2.2へのコピー＆ペースト引き渡し

## 使い方

1. 「探す」タブで目的に近い検索カードを選ぶ
2. GoogleまたはGitHubで募集・練習材料を探す
3. 見つけた内容を「見つけた募集メモ」へ貼る
4. 「この募集を分解する」を押す
5. 必要技術を確認し「技能差分を出す」を押す
6. 作業内容・納品物・質問・チェック基準を確認して修正する
7. 正式案件カードを生成してコピーする
8. 装備庫を開き、案件カードを貼って作業台を作る

## 実装範囲

HTML / CSS / JavaScriptのみを使用しています。外部サイトの自動取得、スクレイピング、ログイン、自動応募、AI API、サーバー処理はありません。
