# 入口アプリ v0.4D｜案件カード状態・未確定情報分離版

募集を探す検索語と入口を持ち、見つけた募集を技能差分判定と正式案件カードを通して「フリーランス装備庫 v2.2」へ渡す静的SPAです。

## v0.4Dでできること

- 「探す」と「分解する」のタブ切り替え
- 6カテゴリ・27枚の目的別検索カード
- Google検索とGitHub Issue検索
- 検索語のコピー
- コピー失敗時の手動コピー表示
- 危険ワードの確認リスト
- 見つけた募集メモ
- 募集メモの防護付き端末内保存
- 募集メモから既存の募集文入力・技能候補・差分判定への引き渡し
- 作業内容・納品物・相手へ聞く質問・チェック基準の確認と修正
- 「確認中」「制作可能」のカード状態判定
- 入力ガイド文と案件の確定情報を分離し、未確定項目を「未確定」として出力
- 未確定事項と依頼主へ聞く質問を案件カード内で分離
- 作業内容・納品物・チェック基準・制作許可がそろった場合だけ「制作可能」にする安全判定
- 装備庫必須4項目を独立見出しで含む正式案件カードの生成
- 学習ミッション完成条件を含む案件カードのコピー
- フリーランス装備庫 v2.2へのコピー＆ペースト引き渡し
- iPhone向け5ステップ表示と現在地表示
- 1画面1工程の「次へ」「戻る」操作
- 正式案件カード直下の「コピーして装備庫へ渡す」操作
- 装備庫必須4見出しの生成後チェック表示
- STEP 1で募集メモ7項目を直接確認・修正
- STEP 2で文章候補・選択中・ほかの技術を整理表示
- STEP 4を装備庫必須4項目の確認に限定
- STEP 5に技能差分・学習ミッション・案件カードを集約
- 案件カードのコピーと装備庫を開く操作を分離

## 使い方

1. 「探す」タブで目的に近い検索カードを選ぶ
2. GoogleまたはGitHubで募集・練習材料を探す
3. 見つけた内容を「見つけた募集メモ」へ貼る
4. 「この募集を分解する」を押す
5. STEP 1で募集メモ7項目を確認する
6. STEP 2で必要技術を選ぶ
7. STEP 3で現在の装備状態を確認する
8. STEP 4で作業内容・納品物・質問・チェック基準を確認し、制作許可が確認できた場合だけチェックを入れる
9. STEP 5で技能差分と学習ミッションを確認し、正式案件カードを生成する
10. カードをコピーして装備庫へ貼り、案件作業台を作る

分解タブでは一度に1つのSTEPだけを表示します。上部の現在地表示から、5工程のどこにいるか確認できます。

作業内容・納品物・チェック基準のいずれかが未確定、依頼主への質問が残っている、または制作許可が未確認の場合、案件カードは「確認中」になります。確認中カードは装備庫で確認作業だけに使い、実制作へ進めません。

## 実装範囲

HTML / CSS / JavaScriptのみを使用しています。外部サイトの自動取得、スクレイピング、ログイン、自動応募、AI API、サーバー処理はありません。
